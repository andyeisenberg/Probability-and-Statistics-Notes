Exercise 1.

A continuous random variable \(X\) taking values in \([1, 4]\) has p.d.f. \(f(x) = k(x - \sqrt{x})\) for some constant \(k\text{.}\)
🔗

(a)

What is the value of \(k\text{?}\)
🔗
Answer.
\(k = \frac{6}{17}.\)
🔗
🔗
🔗

(b)

Find \(\Pr(2 \leq X \leq 3).\)
🔗
Answer.
\(\Pr(2 \leq X \leq 3) \approx 0.325\)
